# Position sizing & drawdown notes

Small script (`risk_math.py`) to test position sizing before risking real money on a trade.

What is inside:
- Position size from account balance, risk %, entry, and stop loss
- How much % gain it takes to climb back out of a drawdown
- What happens to balance after a string of losses in a row

Run it:

```bash
python3 risk_math.py
```
