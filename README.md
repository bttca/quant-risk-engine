# Quant Risk Engine 📈🧮

Python tools for quantitative risk management, position sizing, expectancy modeling, and Monte Carlo drawdown simulation in financial markets.

---

### 🎯 Why This Exists
Most traders fail from poor risk sizing and emotional execution rather than bad entries. This repository turns core **financial mathematics and risk discipline** into testable, reproducible Python tools.

---

### 🧰 Modules & Roadmap
| Module | Purpose | Status |
| :--- | :--- | :--- |
| **`01-position-sizer`** | Calculates exact position size, risk-to-reward ratio, and max loss from account equity & stop-loss distance | 🟡 In Progress |
| **`02-expectancy-calculator`** | Evaluates system edge ($E = (W \times \text{AvgWin}) - (L \times \text{AvgLoss})$) and profit factor | ⬜ Planned |
| **`03-monte-carlo-drawdown`** | Simulates 1,000+ trade sequences to measure probability of ruin and expected max drawdown | ⬜ Planned |
| **`04-trade-journal-analyzer`** | Parses CSV trade logs to spot overtrading, session performance, and rule violations | ⬜ Planned |

---

`Python 3` • `NumPy` • `Pandas` • `CLI`
